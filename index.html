Translation

Translation that reads like a person wrote it

Olingo Chat doesn't translate word by word. It reads the conversation so replies make sense, and it keeps the tone friendly.

  • Understands context

    It reads the last few messages, so short replies like "me too" and the subjects Korean and Japanese often leave out come through correctly.

  • Polite by default

    Korean translations use the friendly polite style (해요체), so nobody sounds rude by accident.

  • Leaves the right things alone

    Names, emoji, links and numbers stay as they are. "ok", "lol" and "haha" don't need a translator.

  • Never leaves you waiting

    The original arrives instantly. If a translation is ever unavailable, you still have the message and a Retry button.

Security

Encrypted on the way. Encrypted at rest.

Every message, translation, photo and file is encrypted while it travels and before it's stored. Here's what happens to a message after you press send.

  1. Sent over HTTPS

    Your message leaves your phone or browser over an encrypted connection, so nobody else on your Wi-Fi or network can read it.

  2. Translated in-house

    Olingo Chat's own server translates it, on the same machine. It's never sent to an outside translation service or AI company.

  3. Encrypted before it's saved

    The message, each translation and any photo or file are encrypted with AES-256 before they're stored.

  4. Delivered over HTTPS

    Everyone in the chat receives it in their own language, over an encrypted connection again.

The key is kept apart

The encryption key is stored separately from your messages. A copy of the database or a backup shows only scrambled text.

Tampering is detected

Each message is sealed to the exact place it's stored. If saved data is altered, swapped or cut short, Olingo Chat notices.

Every access is logged

Olingo Chat's admin tools list chats without their content. Opening one, for example to look into an abuse report, needs a written reason, recorded before anything is shown.

Sign-in that's hard to steal

Passwords are hashed with Argon2, never stored as typed. Sign-in tokens are kept only as hashes, so even a leaked database can't sign anyone in.

Locked down on your phone

Your sign-in is kept in the phone's secure storage, and Olingo Chat can ask for your fingerprint or face before it opens.

You decide who reaches you

Let everyone message you, only people in your groups, or nobody new. Block anyone, and sign out any device you don't recognise.

Is Olingo Chat end-to-end encrypted?

No. To translate a message, the server has to read it, and end-to-end encryption would prevent that. Instead, messages are encrypted on the way and in storage, and the server decrypts them to translate and deliver them, on Olingo Chat's own hardware.

Technical details
  • Stored text (messages, translations and file names): AES-256-GCM with a fresh random 96-bit nonce for every value, bound to where it's stored so it can't be moved to another message unnoticed.
  • Files: encrypted while they upload, in 64 KiB pieces sealed with AES-256-GCM under a key made for that one file (HKDF-SHA256). The last piece is marked, so a shortened or reordered file is rejected.
  • Connections: HTTPS (TLS) for the web app, the API and the live WebSocket connection.
  • Passwords: Argon2id. Sign-in tokens: 256-bit random values, stored only as SHA-256 hashes and replaced every time they're refreshed. Changing your password signs out your other devices.
  • Sessions: in the browser, HttpOnly, Secure, SameSite=Strict cookies that page scripts can't read; on phones, the system's secure storage.
  • QR sign-in: a code alone never signs anyone in. A device that's already signed in has to approve the new one, and each code expires after 2 minutes and works once.

FAQ

Questions people ask

Do I need an invite?

Yes, for now. Olingo Chat is invite-only while it grows. Enter the code you received when you create your account.

How good is the translation?

Olingo Chat uses a modern AI model that understands context, slang and tone, and keeps names, emoji and links as they are. No translation is perfect, so the exact original is always one tap away.

Are my messages encrypted?

Yes. Messages, translations, photos and files travel over encrypted HTTPS connections, and they're encrypted with AES-256 before they're stored. The key is kept apart from the database, so a copy of it or a backup shows only scrambled text.

Is Olingo Chat end-to-end encrypted?

No. Translation needs the server to read a message, which end-to-end encryption would prevent. Olingo Chat translates on its own server, never with an outside service, and opening a chat as an admin takes a written reason that is logged first.

Can other people see what I originally wrote?

Yes. Anyone in the chat can tap Show original to see your exact words, just as you can with theirs.

What happens if I change my language?

Go to Settings, then Profile, and pick a new language. New messages arrive in it right away, and older messages are translated when you scroll back to them.

Which devices does Olingo Chat work on?

Any computer with a modern web browser, and Android phones. An iPhone app is coming. Your chats are the same on every device, and you can sign in on a computer by scanning a QR code with your phone.

How do I install the Android app?

Download the APK on your phone and open it. When Android asks, allow your browser to install apps, then tap Install. New versions install over the old one, and your chats stay where they are.

What happens to my messages if I delete my account?

Deleting your account permanently removes it, along with the messages and files you sent. Groups that are left with no members are removed too.
